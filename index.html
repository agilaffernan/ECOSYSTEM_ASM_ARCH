ASM+ on Google Cloud

A navigable, evidence-grounded architecture baseline for the live ASM+ deployment in Google Cloud. The package combines ten focused manuals, twenty-one visual diagrams, and the complete Structurizr model.

Architecture Manuals

1. System Context

Explains where ASM+ lives, who uses it, which enterprise systems connect to it, and which Google Cloud services form its external operating context.

Open manual

2. Container / Microservices

Shows the eight deployed workloads, their responsibilities, public or internal exposure, and their principal runtime dependencies.

Open manual

3. Component Architecture

Decomposes each frontend and API into its principal code responsibilities so maintainers can see where authentication, business logic, persistence, and integration behavior live.

Open manual

4. API / Integration

Documents public endpoints, internal service calls, protocols, and authentication controls used by browser, SAP, Salesforce, database, and object-storage traffic.

Open manual

5. Data Architecture

Separates relational metadata from binary object storage, groups the live PostgreSQL tables by domain, and explains how application APIs coordinate both stores.

Open manual

6. Deployment Architecture

Maps the logical services to their live GCP resources: DNS, load balancer, zonal GKE cluster, pods and sidecars, Cloud SQL, GCS, Artifact Registry, Secret Manager, and Cloud Operations.

Open manual

7. Network Architecture

Traces public traffic from DNS and the external load balancer to GKE NEGs, and traces private service traffic to Cloud SQL and GCS.

Open manual

8. Security Architecture

Explains TLS, JWT and integration authentication, secret injection, Workload Identity, protected data paths, and the current security gaps observed in the deployment.

Open manual

9. Runtime / Sequence

Walks through the principal interactive and integration flows: SSO, document upload, document viewing, SAP ArchiveLink writes, and Salesforce writes.

Open manual

10. Observability

Documents the health probes, logs, platform metrics, and monitoring coverage that exist today, together with the custom alerting and dashboard gaps still present.

Open manual

How to Use This Package

  1. Start with System Context, then Container / Microservices.
  2. Use the focused manuals for component, data, network, security, runtime, and operations detail.
  3. Open the interactive Structurizr viewer to navigate between linked C4 views.
  4. Consult the traceability and assumptions files before treating an observation as a design guarantee.
