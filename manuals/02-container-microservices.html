Configuration and Secret Injection

Non-secret runtime settings are supplied from Kubernetes ConfigMaps. Sensitive values are injected from the namespace-scoped asmplus-runtime-secrets Secret. The observed key names are documented in the Security manual; values are intentionally excluded.

Four database-backed APIs run a Cloud SQL Auth Proxy 2.14.1 sidecar. The proxy uses private IP and the cloudsql-client Workload Identity mapping. The application process connects only to localhost.

Scaling and Availability Characteristics

Each workload currently has one application replica. Three e2-medium nodes were Ready in the zonal GKE cluster. Readiness and liveness probes gate availability, but a single application replica means a rollout or pod disruption can temporarily reduce that workload to zero ready replicas.

Current topology. The cluster is zonal in us-east1-b and Cloud SQL is zonal. This is a functional deployment, not a multi-zone high-availability design.
